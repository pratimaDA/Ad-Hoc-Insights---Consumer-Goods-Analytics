# 📊 AtliQ Hardware — Ad-Hoc Business Insights

## 📌 Project Overview

Analyzed ad-hoc business queries using SQL and Power BI to help AtliQ Hardwares make data-driven decisions.

## 🏢 Business Problem

Despite its global presence, AtliQ Hardwares identified a lack of actionable insights to support quick and data-driven decision-making.

To address this challenge, the management aimed to enhance its analytics capabilities by conducting a SQL challenge to identify skilled data analysts who could derive meaningful insights from business data.

## 🎯 Project Objective

The objective of this project was to:

* Analyze AtliQ Hardware's business data to derive actionable insights.
* Solve 10 ad-hoc business queries using SQL.
* Support management in making informed, data-driven decisions.
* Present key insights through visualizations and effective storytelling.

## 🛠️ Tools Used

| Tool                      | Purpose                                                         |
| ------------------------- | --------------------------------------------------------------- |
| **SQL (MySQL Workbench)** | Querying, analyzing, and extracting business insights from data |
| **Power BI**              | Data visualization and dashboard development                    |
| **Microsoft PowerPoint**  | Presenting business insights effectively                        |

## 💡 SQL Concepts Learned

* **Joins:** Combined data from multiple tables efficiently using different types of JOINs.
* **Aggregations:** Used `COUNT()`, `SUM()`, `AVG()`, `MAX()` and `MIN()` to summarize business data.
* **Filtering:** Applied `WHERE` and `HAVING` clauses for precise data filtering.
* **Sorting and Limiting:** Organized query results using `ORDER BY` and `LIMIT`.
* **Subqueries:** Extracted intermediate datasets to simplify complex queries.
* **Common Table Expressions (CTEs):** Improved query readability, structure, and reusability.
* **Window Functions:** Applied `SUM() OVER()` and `RANK()` to perform advanced analytical calculations across table partitions.
